## 本机窗口隐藏验证

在 Loon 3.5.2 上单独验证了实际隐藏子程序：短暂显示现有窗口，再调用隐藏逻辑。
系统状态从未隐藏变为已隐藏，应用进程 ID 保持不变，未退出 Loon。
这项验证没有发送开关 VPN 或更新订阅的 URL，也未修改已安装的定时任务。

第一次尝试发现：即时请求返回值可能让脚本误报失败，而后续独立读取已经是隐藏状态。
修复采用推进运行循环后读取的隐藏状态确认结果；修正后的本机验证通过。
